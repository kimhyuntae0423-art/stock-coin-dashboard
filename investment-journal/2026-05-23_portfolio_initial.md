## 3. 사전 룰 (감정 개입 차단) — 진입 전에 작성한 룰만 따른다

### 매수 룰
- **Core**: 매월 자동이체. 시장 타이밍 고려하지 않는다. 폭락은 기회.
- **Satellite**: 무조건 분할매수 3회. 1회 풀매수 금지.

### 손절 룰
- **Core**: 손절 없음. 장기 보유.
- **Satellite**:
  - 매수 평균단가 -20% 도달 시 손절 검토
  - 데드크로스(50일선 < 200일선) 발생 시 1/3 정리
  - 점수 ≤ -0.5 떨어지면 절반 정리

### 추가매수 룰
- **Core**: 시장 -15% 조정 시 Cash로 추가매수
- **Satellite**: 매수가 -5%, -10% 조정 + 펀더 변화 없음 + 점수 +0.0 이상 유지 시 분할 추가

### 매도 룰
- **Core**: 매도하지 않음 (퇴직 시점에 분할 인출)
- **Satellite**:
  - 점수 ≤ -1.0 (강한 매도 시그널)
  - 또는 분기 EPS 컨센서스 -20% 하향
  - 또는 ROE 2분기 연속 하락

### 리밸런싱 룰
- **분기 1회**: 목표 비중 ±5%p 이탈 시 조정
- 비싸진 자산 일부 매도 → 싸진 자산 추가매수 (자동 mean-reversion)

1. **점수 1·2위 = 미래 수익률 1·2위 보장 아님** (학술적으로 불가능)

3. **현금 비중 = 폭락 시 알파** — 0%로 만들지 말 것
4. **장기 시계 = 변동성이 친구** — 단기 하락에 흔들리지 말 것
5. **모든 룰은 진입 전에 작성** — 매수 후 감정으로 룰 변경 금지
