# 📓 투자 일지

이 폴더는 사용자의 **투자 논리 + 매수 사유 + 틀릴 조건**을 기록하는 곳이다.

## 왜 기록하는가?

> *주가가 떨어졌을 때 흔들리는 미래의 자신에게 보내는 편지.*

매수 당시의 논리를 시간이 지나면 잊는다. 손실/이익이 발생하면 그 감정이 원래 논리를
왜곡시킨다. 기록만이 흔들림 속에서 객관성을 지켜준다.

## 사용법

### 새 종목 등록
메인 채팅에서: "삼성전자 매수했어. 기록해줘"
→ `journal-keeper` 에이전트가 `_template.md` 기반으로 새 파일 생성.

### 점검 (decision-coach 자동 참조)
"팔까?", "더 살까?" 같은 질문 시 `decision-coach`가 먼저 이 폴더에서
해당 종목 파일을 읽어 **기존 매수 논리**를 다시 보여준다.

### 갱신
실적 발표 후, 분기 점검, 산업 변화 시 기존 파일 하단에 `## 업데이트 — YYYY-MM-DD` 추가.
*절대 기존 내용 덮어쓰지 않는다.* 시계열로 누적.

## 파일명 규칙

```
{YYYY-MM-DD}_{ticker}_{종목명}.md
```

예시:
- `2026-05-19_005930.KS_삼성전자.md`
- `2026-05-19_NVDA_엔비디아.md`

## 폴더 구조

```
investment-journal/
├── README.md                       # 이 파일
├── _template.md                    # 작성 양식
├── morning-notes/                  # (옵션) 데일리 모닝 노트 저장
│   └── 2026-05-19.md
└── {entries}.md                    # 종목별 기록
```

## 규칙

- **모든 매수/관심 종목은 등록**한다. 등록 없이 매매하면 미래의 자신이 욕한다.
- **틀릴 조건은 정량적**으로 — "주가 빠지면" 같은 모호한 표현 금지.
  예: "분기 매출 YoY -5% 이하 2분기 연속" / "PER 5년 평균 +50% 이상으로 확장"
- **매도 후에도 파일 유지** — 다음에 같은 종목 볼 때 과거 판단을 학습 자료로.
- 파일은 절대 삭제하지 않는다. 잘못된 매수도 자산이다.
